# TASK-202: ゲームモード・ステート実装 - TDD要件定義書

## 実装概要

Bird Dive Challengeのゲームモード・ステート実装として、ゲーム開始/終了フロー、難易度選択システム、スコア計算ロジック、タイマー管理、ゲーム状態遷移を実装する。

## 詳細要件

### 1. ゲーム開始/終了フロー

#### 1.1 ゲーム開始処理
- **要件ID**: REQ-TASK202-001
- **機能**: 難易度選択後のゲーム初期化とゲーム開始
- **詳細**:
  - 選択された難易度に基づく物理パラメータ設定
  - タイマーの初期化と開始
  - スコアのリセット
  - 鳥キャラクターの初期位置設定
  - ゲーム状態をEGameState::Playingに変更

#### 1.2 ゲーム終了処理
- **要件ID**: REQ-TASK202-002
- **機能**: 着地判定後のゲーム終了処理
- **詳細**:
  - タイマー停止
  - 最終スコア計算
  - 着地結果の評価
  - ゲーム状態をEGameState::GameOverに変更
  - リザルトデータの準備

### 2. 難易度選択システム

#### 2.1 難易度パラメータ管理
- **要件ID**: REQ-TASK202-003
- **機能**: 3つの難易度レベル (Easy/Normal/Hard) の設定管理
- **詳細**:
  - Easy: 風力強度0.5倍、重力0.8倍、スコア倍率1.0倍、制限時間90秒
  - Normal: 風力強度1.0倍、重力1.0倍、スコア倍率1.2倍、制限時間60秒  
  - Hard: 風力強度1.5倍、重力1.2倍、スコア倍率1.5倍、制限時間45秒

#### 2.2 難易度適用処理
- **要件ID**: REQ-TASK202-004
- **機能**: 選択された難易度の物理・ゲーム設定への適用
- **詳細**:
  - 風力システムへの強度係数設定
  - 重力システムへの係数設定
  - スコア計算システムへの倍率設定
  - ゲームタイマーの制限時間設定

### 3. スコア計算ロジック

#### 3.1 基本スコア計算
- **要件ID**: REQ-TASK202-005
- **機能**: 着地品質に基づく基本スコア算出
- **詳細**:
  - Perfect: 1000点 (的中心から10単位以内)
  - Good: 500点 (的中心から50単位以内)
  - Poor: 100点 (的中心から100単位以内)
  - Miss: 0点 (的外れ)

#### 3.2 ボーナススコア計算
- **要件ID**: REQ-TASK202-006
- **機能**: 時間・速度ボーナスの計算
- **詳細**:
  - 時間ボーナス: (制限時間 - 経過時間) × 10
  - 速度ボーナス: (1000 - 着地速度) × 2 (ただし0以上)
  - 難易度ボーナス: 基本スコア × 難易度倍率

#### 3.3 最終スコア統合
- **要件ID**: REQ-TASK202-007
- **機能**: 基本スコアとボーナススコアの統合
- **詳細**:
  - 最終スコア = (基本スコア + ボーナススコア) × 難易度倍率
  - オーバーフロー防止: 最大値999,999に制限
  - マイナススコア防止: 最小値0に制限

### 4. タイマー管理

#### 4.1 ゲームタイマー
- **要件ID**: REQ-TASK202-008
- **機能**: ゲームプレイ時間の計測と制限時間管理
- **詳細**:
  - ゲーム開始時に0.0秒からカウント開始
  - 毎フレーム経過時間を更新
  - 制限時間到達時に強制終了
  - 着地時にタイマー停止

#### 4.2 タイマー状態管理
- **要件ID**: REQ-TASK202-009  
- **機能**: タイマーの開始・停止・リセット機能
- **詳細**:
  - StartGameTimer(): ゲーム開始時のタイマー開始
  - StopGameTimer(): ゲーム終了・着地時のタイマー停止
  - ResetGameTimer(): 新しいゲーム開始時のリセット
  - GetElapsedTime(): 現在の経過時間取得

### 5. ゲーム状態遷移

#### 5.1 状態遷移システム
- **要件ID**: REQ-TASK202-010
- **機能**: EGameStateを使った状態管理と遷移制御
- **詳細**:
  - Menu → Playing: StartGame()呼び出し時
  - Playing → GameOver: 着地判定時またはタイムアップ時
  - Playing → Paused: 一時停止時
  - Paused → Playing: 再開時
  - GameOver → Results: スコア計算完了時
  - Results → Menu: メニューに戻る時

#### 5.2 状態変更通知
- **要件ID**: REQ-TASK202-011
- **機能**: ゲーム状態変更時の通知システム
- **詳細**:
  - OnGameStateChanged デリゲートによる通知
  - UIシステムへの状態変更通知
  - 各システムの状態同期
  - ログ出力による状態遷移の記録
