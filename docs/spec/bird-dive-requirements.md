# Bird Dive Challenge 要件定義書

## 概要

Bird Dive Challengeは、鳥が高所から地面の的を目指して降下するスコアアタック型アクションゲームです。風の影響を受けながら正確に着地することで高得点を狙います。

- **開発環境**：Unreal Engine 5.6
- **ジャンル**：スコアアタック型落下アクション
- **プラットフォーム**：PC（Windows）
- **対象ユーザー**：カジュアルゲーマー

## ユーザストーリー

### ストーリー1: ゲームプレイの基本体験

- **である** プレイヤー **として**
- **私は** 鳥を操作して高所から地面の的に正確に着地 **をしたい**
- **そうすることで** スコアアタックの爽快感と挑戦の楽しさを得られる

### ストーリー2: 難易度選択

- **である** プレイヤー **として**
- **私は** 自分のスキルレベルに応じて難易度（Easy/Normal/Hard）を選択 **をしたい**
- **そうすることで** 適切な挑戦レベルでゲームを楽しめる

### ストーリー3: 視覚的フィードバック

- **である** プレイヤー **として**
- **私は** 2つの視点（主観視点・横視点）で鳥の降下状況を確認 **をしたい**
- **そうすることで** 正確な操作と臨場感のある体験ができる

### ストーリー4: 着地エフェクト

- **である** プレイヤー **として**
- **私は** 着地時に派手なエフェクトを見る **をしたい**
- **そうすることで** 達成感と視覚的満足感を得られる

## 機能要件（EARS記法）

### 通常要件

- REQ-001: システムは鳥キャラクターを重力に従って落下させなければならない
- REQ-002: システムは2画面分割表示（主観視点・横視点）を提供しなければならない
- REQ-003: システムは着地位置と到達タイムに基づいてスコアを算出しなければならない
- REQ-004: システムは着地時にNiagaraエフェクトを再生しなければならない
- REQ-005: システムはプレイヤーの入力に応じて鳥の方向を制御できなければならない
- REQ-006: システムは難易度選択画面を提供しなければならない
- REQ-007: システはゲーム開始からリザルト表示まで一連の流れを実行しなければならない

### 条件付き要件

- REQ-101: プレイヤーがEasy難易度を選択した場合、システムは風の強さを弱く設定しなければならない
- REQ-102: プレイヤーがNormal難易度を選択した場合、システムは風の強さを標準に設定しなければならない
- REQ-103: プレイヤーがHard難易度を選択した場合、システムは風の強さを強く設定しなければならない
- REQ-104: 鳥の着地速度が許容値を超えた場合、システムは失格判定を行わなければならない
- REQ-105: 鳥が地面に接触した場合、システムは着地判定処理を実行しなければならない
- REQ-106: ゲーム中にプレイヤーが操作入力を行った場合、システムは鳥の移動方向を調整しなければならない
- REQ-107: 主観視点カメラの速度が一定値を超えた場合、システムはポストプロセスで歪みエフェクトを適用しなければならない

### 状態要件

- REQ-201: ゲームが進行中の状態にある場合、システムは経過時間を表示しなければならない
- REQ-202: ゲームが進行中の状態にある場合、システムは現在のスコアを表示しなければならない
- REQ-203: 失格状態が発生した場合、システムは失格メッセージを表示しなければならない
- REQ-204: ゲーム終了状態の場合、システムはリザルト画面を表示しなければならない

### オプション要件

- REQ-301: システムはリプレイ機能を提供してもよい
- REQ-302: システムはハイスコアランキング機能を提供してもよい
- REQ-303: システムは操作設定のカスタマイズ機能を提供してもよい
- REQ-304: システムは効果音の音量調整機能を提供してもよい

### 制約要件

- REQ-401: システムはUnreal Engine 5.6で動作しなければならない
- REQ-402: システムはWindows PCで60FPS以上で動作しなければならない
- REQ-403: システムは1024x768以上の解像度をサポートしなければならない
- REQ-404: システムはControlRigを使用してアニメーションを制御しなければならない

## 非機能要件

### パフォーマンス

- NFR-001: ゲームは60FPS以上で安定動作すること
- NFR-002: ゲーム開始からプレイ可能状態まで3秒以内であること
- NFR-003: シーン遷移は1秒以内で完了すること
- NFR-004: メモリ使用量は4GB以下に抑えること

### ユーザビリティ

- NFR-101: 操作方法は直感的で、チュートリアルなしでも理解できること
- NFR-102: UI要素は画面の10%以下の領域に収めること
- NFR-103: 重要な情報（スコア、タイマー）は常に視認可能であること
- NFR-104: 色覚異常者にも配慮したカラーパレットを使用すること

### 品質

- NFR-201: ゲームクラッシュやフリーズが発生してはならない
- NFR-202: 物理演算の異常な挙動が発生してはならない
- NFR-203: サウンドの遅延や途切れが発生してはならない

### 保守性

- NFR-301: パラメータ調整はBlueprint上で容易に変更可能であること
- NFR-302: アセットの追加・変更が容易に行えること
- NFR-303: デバッグ情報の表示・非表示が切り替え可能であること

## Edgeケース

### エラー処理

- EDGE-001: アセットファイルが見つからない場合、デフォルトアセットで代替する
- EDGE-002: 物理演算が破綻した場合、鳥の位置をリセットする
- EDGE-003: スコア計算でオーバーフローが発生した場合、最大値で制限する
- EDGE-004: カメラが異常な位置に移動した場合、初期位置に戻す

### 境界値

- EDGE-101: 着地速度が0の場合の処理を定義する
- EDGE-102: 着地位置が的の範囲外の場合の得点計算を定義する
- EDGE-103: ゲーム時間が0秒の場合の処理を定義する
- EDGE-104: 風の強さが0または最大値の場合の挙動を定義する

### 異常系

- EDGE-201: 連続でゲームを開始した場合の初期化処理
- EDGE-202: ゲーム途中で難易度が変更された場合の処理
- EDGE-203: 複数の着地判定が同時に発生した場合の処理
- EDGE-204: Niagaraエフェクトの再生に失敗した場合の代替処理

## 受け入れ基準

### 機能テスト

- [ ] 3つの難易度でそれぞれ正常にゲームが開始できる
- [ ] 鳥が重力に従って落下する
- [ ] プレイヤー入力に応じて鳥の方向が変化する
- [ ] 風の影響で鳥が横方向に流される
- [ ] 2画面表示が正常に機能する
- [ ] 着地時にエフェクトが再生される
- [ ] 速度超過時に失格判定が機能する
- [ ] スコアが正しく計算・表示される
- [ ] リザルト画面が表示される
- [ ] ControlRigによるアニメーションが動作する

### 非機能テスト

- [ ] 60FPS以上で安定動作する
- [ ] メモリ使用量が4GB以下である
- [ ] ゲーム開始が3秒以内である
- [ ] 1024x768解像度で正常表示される
- [ ] 長時間プレイでもクラッシュしない

### 統合テスト

- [ ] 全ての難易度で完全なゲームサイクルが実行できる
- [ ] UI要素が全て正常に表示・更新される
- [ ] サウンドエフェクトが適切なタイミングで再生される
- [ ] ポストプロセスエフェクトが速度に応じて変化する
