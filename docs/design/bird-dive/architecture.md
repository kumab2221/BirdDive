# Bird Dive Challenge アーキテクチャ設計

## システム概要

Bird Dive Challengeは、Unreal Engine 5.6を基盤とした単体のゲームアプリケーションです。鳥キャラクターの物理ベースの落下シミュレーション、リアルタイムの風力計算、2画面分割レンダリング、ControlRigによるプロシージャルアニメーション、Niagaraエフェクトシステムを統合したスコアアタック型ゲームです。

## アーキテクチャパターン

- **パターン**: Component-Entity-System (CES) + MVC Hybrid
- **理由**: 
  - Unreal Engineの標準的なActor-Componentアーキテクチャに適合
  - ゲームプレイ要素の疎結合化とモジュール性の確保
  - 物理演算、アニメーション、エフェクトの独立した管理

## コンポーネント構成

### ゲームプレイレイヤー

#### コアゲームプレイ
- **ゲームモード**: `ABirdDiveGameMode`
  - ゲームの全体的な流れの管理
  - 難易度設定の適用
  - スコア計算とリザルト処理
- **ゲームステート**: `ABirdDiveGameState`
  - ゲーム進行状態の管理
  - タイマー管理
  - スコアデータの保持
- **プレイヤーコントローラー**: `ABirdDivePlayerController`
  - 入力の受付と処理
  - カメラ制御の統括
  - UI表示の制御

#### キャラクター
- **鳥キャラクター**: `ABirdCharacter`
  - Pawn基底クラス継承
  - 物理ベースの移動システム
  - CharacterMovementComponentカスタマイズ

### レンダリングレイヤー

#### カメラシステム
- **分割スクリーン管理**: `USplitScreenManager`
  - 2画面分割レンダリング
  - ビューポート管理
  - カメラ切り替え制御
- **主観視点カメラ**: `ABirdFirstPersonCamera`
  - 鳥の頭部追従
  - 速度ベースのポストプロセス
  - FOV動的調整
- **横視点カメラ**: `ABirdSideViewCamera`
  - 鳥の水平追従
  - 固定カメラアングル
  - スムーズな追従システム

#### エフェクトシステム
- **Niagara統合**: `UBirdEffectManager`
  - 着地エフェクトの管理
  - パーティクルシステムのプール
  - エフェクトのライフサイクル管理

### アニメーションレイヤー

#### ControlRigシステム
- **鳥リグ**: `UCR_BirdRig`
  - 羽ばたきアニメーション
  - 風による姿勢制御
  - プロシージャル羽根制御
- **アニメーションブループリント**: `ABP_Bird`
  - 状態マシン管理
  - ブレンドスペース制御
  - 物理アニメーション統合

### 物理レイヤー

#### 風力システム
- **風力計算**: `UWindForceComponent`
  - Perlinノイズベースの風力生成
  - 難易度別パラメータ適用
  - リアルタイム外力適用
- **物理演算**: Custom CharacterMovementComponent
  - 重力制御
  - 空気抵抗シミュレーション
  - 着地判定

### UIレイヤー

#### UMGシステム
- **メインUI**: `UW_GameplayHUD`
  - スコア表示
  - タイマー表示
  - 速度インジケーター
- **メニューシステム**: `UW_MainMenu`
  - 難易度選択
  - 設定画面
  - リザルト表示

### データレイヤー

#### 設定データ
- **難易度設定**: `UDifficultyDataAsset`
  - 風力パラメータ
  - 許容速度閾値
  - スコア倍率
- **ゲーム設定**: `UGameConfigDataAsset`
  - カメラ設定
  - エフェクト設定
  - サウンド設定

## システム相互作用

### 主要なサブシステム間の関係

1. **ゲームフローマネージャー**
   - GameMode → GameState → PlayerController
   - UI更新とゲーム状態の同期

2. **物理シミュレーション**
   - WindForceComponent → CharacterMovement → BirdCharacter
   - 物理演算結果のアニメーションシステムへの反映

3. **レンダリングパイプライン**
   - SplitScreenManager → Camera System → Rendering
   - 2画面同期レンダリング

4. **エフェクト統合**
   - EffectManager → Niagara System → Material System
   - 着地イベントトリガーベースのエフェクト再生
